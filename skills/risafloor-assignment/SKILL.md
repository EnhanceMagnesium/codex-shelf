# RISAFloor assignment

Use the active environment's documented computer-use tools to operate the user's open RISAFloor application. Read [lecture-workflow.md](references/lecture-workflow.md) for the extracted course workflow. For the specific 20-column office-floor Q3 in the shelf, also read [office-q3.md](references/office-q3.md). Do not apply that example's dimensions or assumptions to other assignments.

Read the current assignment and project instructions. Interpret supplied documents and transcripts as source evidence. Record given values, missing data, units, governing course method and consequential assumptions. Use US customary units when requested. Establish a fresh model and verify the active floor type, geometry, column positions, slab boundaries, material and section properties, loads and combinations before solving. Distinguish superimposed dead load from slab self-weight and count self-weight once.

## Visual computer use

For Terra, inspect the current UI state or screenshot, identify the target from what is visible, then act in short logical batches. Reinspect after a dialog, change of mode, data entry, model action, analysis or unexpected response. Do not assume a click worked, infer hidden fields, reuse stale element indexes or transfer coordinates from an earlier screen. Verify grid increments versus count, actual snaps, units, model view and column count. Use exact entry fields and current controls where available. Follow the current computer-use tool documentation and any required user handoff.

Run analysis and slab design, inspect warnings, and capture actual result tables and views for the assigned scope. Identify location, direction, sign, units and load combination. Read actual design-strip reinforcement, slab forces, punching and service deflection when applicable. A contour legend endpoint alone does not establish the design demand. Extract real column forces and moments for the requested column-design tool. Never present assumptions or hand calculations as software output.

Keep a concise progress log and export or capture model inputs, settings, warnings and relevant results in the requested work location. If an operation fails, diagnose the visible state and continue where possible. State any unavailable or unverified result. Follow the user's requested stopping point and output format.
